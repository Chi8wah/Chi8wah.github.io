一键爆款复刻 Prompt Director

上传 1-3 张商品图和一个参考视频，先做完整参考视频事实观察和商品/世界资产圣经，再输出可复制到即梦 Seedance 2.0 的 <=15 秒分段 Prompt 队列。

只做 Prompt Director不调用 Seedance；参考视频 URL 用于精细切分，URL 模式下也用于 Gemini 理解。
Gemini 多模态理解参考视频可通过 URL fileData 或本地 inlineData 输入；商品图片仍转成 inlineData 发送到配置的 Gemini 接口。
Seedance 手动执行最终输出使用 @图片1 / @视频N 手柄；用户需先手动裁切并上传对应参考视频分段，复制到即梦后由人工检查。
Ready阶段 1: 参考视频解析

只做完整参考视频事实观察：时序、镜头、动作、构图、视觉、声音、广告结构和事实风险。可先单独跑精细切分，后续完整阶段 1 会在 URL 一致时复用结果。

输入：参考视频 URL，或恰好 1 个参考视频文件；阶段 1 按整条参考视频分析。
输出：videoMeta、rawVideoObservations.spokenContent、factualRiskInventory。
约束：允许超过 15 秒的参考视频；读不到时长也允许继续，并要求 Gemini 按整条视频理解。
选择新视频文件会清空下方 URL，避免误复用旧链接；Checkpoint 不保存视频二进制文件。
URL 模式继续使用 fileData.fileUri；inlineData 模式会把本地视频转成 base64 放入请求体，适合较小视频，可能因 base64/请求体过大触发 413；File API 模式暂不可用。
URL 模式下阶段 1 会用该 URL 做精细切分和 Gemini 视频理解；inlineData 模式下该 URL 只用于精细切分，Gemini 使用本地选择的视频，URL 为空时会先上传到 BoolVideo 获取精细切分 URL。若同时选择文件和填写 URL，运行时会先确认二者是否对应。
